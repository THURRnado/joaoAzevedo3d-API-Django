Sobre o Projeto

Este projeto foi criado com o intuito de ajudar no controle e na adição de informações sobre os objetos que estarão expostos no Memorial de João Azevedo. Além disso, ele também servirá como uma API para que outros projetos possam utilizar esses dados de forma integrada, ampliando seu potencial de uso e facilitando futuras soluções que dependam dessas informações.

Gestão de Informações

Adicione, edite e organize dados sobre cada objeto presente no memorial.

Integração com Aplicações

Permite que outros projetos utilizem os dados centralizados deste sistema.
